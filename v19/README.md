# EGX PRO V19 — GitHub Edition

إعادة بناء GitHub-only لواجهة التطبيق المطلوبة، بدون Vercel أو Render أو أي استضافة تطبيق خارج GitHub.

## التشغيل

بعد الدمج إلى `main` تعمل الواجهة من GitHub Pages على:

`https://rasheadsca-star.github.io/RAS-EGX0.1/v19/`

## المصدر والتشغيل

- الواجهة Static HTML/CSS/JavaScript.
- ملفات الواجهة مستنسخة من آخر مصدر Static موثّق داخل هذا المستودع، مع مدخل V19 مستقل.
- بيانات السوق تُقرأ من `../data/v20/` داخل نفس مستودع GitHub؛ تحديثها يتم عبر GitHub Actions الحالية.
- لا توجد أي تبعية Runtime على Vercel.
- رابط Vercel الأصلي كان محميًا بتسجيل دخول، لذلك هذه إعادة بناء من مصدر GitHub الموثّق وليست نسخًا مباشرًا لملفات Deployment المحمية.

## حدود التوافق

الاسم والمسار V19 مستقلان، بينما محرك البيانات الحالي هو مصدر GitHub التنفيذي الموجود بالمستودع للحفاظ على بيانات حديثة وعدم تجميد نسخة تاريخية قديمة.
